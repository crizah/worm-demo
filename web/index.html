how worm replicates

  1. migrate-schema — reads the source schema, recreates it on the target.
  2. migrate-data — snapshots and backfills existing rows, then opens a logical replication slot and streams every insert/update/delete from that point forward.
  3. migrate-resume — picks the stream back up from the last confirmed position after a restart. nothing is replayed, nothing is lost.

the dial on the demo tab controls a live traffic generator writing directly to the source postgres database. every one of those writes is what you're watching get replicated in real time.
